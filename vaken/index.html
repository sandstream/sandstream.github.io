Vaken

Vaken håller en MacBook vaken med stängt lock medan kodagenter som Claude Code och Codex arbetar. När agenterna är klara får datorn sova igen.

Ladda ner Vaken för Mac

Testversion (pre-release). Den senaste versionen ligger överst på sidan med versioner. Kräver macOS 15 eller senare och en Mac med Apple-processor. Signerad av Sandstream AB och notariserad av Apple.

Vad Vaken gör

  • Ser agenterna. Vaken känner igen Claude Code och Codex som arbetar på datorn. Med Koppla Claude Code får Vaken också besked från Claude Code när ett svar är klart.
  • Håller datorn vaken. Medan en agent arbetar sover datorn inte, inte heller med stängt lock.
  • Släpper när arbetet är klart. När agenterna är klara får datorn sova som vanligt.
  • Skyddar datorn. Vaken låter datorn sova om den blir för varm, om batteriet når 20 procent utan laddare, eller om appen slutar svara i 90 sekunder.
  • Uppdaterar sig själv. Vaken installerar nya versioner när ingen agent håller datorn vaken och panelen är stängd. Du kan stänga av det under Inställningar i panelen.

Installera

  1. Öppna sidan med versioner och ladda ner DMG-filen för den översta versionen.
  2. Kontrollera filen om du vill. Kör shasum -a 256 Vaken-*.dmg i Terminal och jämför summan med filen som slutar på .sha256.
  3. Öppna DMG-filen och dra Vaken till Program.
  4. Starta Vaken. Godkänn hjälpprocessen i Systeminställningar under Inloggningsobjekt när Vaken frågar.

Har du redan Vaken 0.2.0 eller senare installerar Vaken nya versioner själv.

Så fungerar det

  • En hjälpprocess med administratörsrätt sätter macOS inställning för att inte sova. Hjälpprocessen återställer inställningen när den startar, när den stoppas och när appen slutar svara.
  • Koppla Claude Code lägger till krokar i ~/.claude/settings.json. Vaken sparar en kopia av filen först.
  • Avinstallera i panelens sidfot låter datorn sova som vanligt, tar bort krokarna och hjälpprocessen, och flyttar Vaken till papperskorgen.

Integritet

  • Vaken läser bara vilka agentprocesser som körs. Vaken läser inte vad agenterna gör.
  • Vaken frågar GitHub efter nya versioner vid start och en gång per dygn. GitHub ser då datorns IP-adress. Ingenting om dig skickas.
  • Före en uppdatering kontrollerar Vaken att appen är signerad av Sandstream AB och notariserad av Apple.
