# sandstre.am — Peter Sandström

Portfolio site for Peter Sandström, hands-on tech lead and consultant.

Live at **[sandstre.am](https://www.sandstre.am)**

## Stack

Plain static HTML served by GitHub Pages — no build pipeline, no framework.

- **React 18** via CDN (version-pinned, SRI-hashed); components are written in `*.jsx` and the
  compiled `*.js` next to each one is what the pages load (see *JSX and the CSP* below)
- **Content-Security-Policy** in a `<meta>` tag on every page, generated by `scripts/csp.mjs`
- **Google Fonts**: Instrument Serif · Geist · JetBrains Mono
- **CSS**: `colors_and_type.css` (design tokens) + `portfolio.css` (layout/components)
- **Content**: `data.js` (T translations, CASES, ROLES arrays)
- **i18n**: Swedish (default) / English toggle via query-free state

## JSX and the CSP

Every page carries a strict Content-Security-Policy: no `'unsafe-eval'`, no `'unsafe-inline'` for
scripts or styles. Two committed outputs keep it that way, and both have a `--check` mode that
fails when the output no longer matches its source:

```bash
# 1. After editing any *.jsx: regenerate the *.js the pages load (TypeScript compiler only).
TSC=/path/to/typescript/bin/tsc node scripts/build-jsx.mjs   # or with tsc on PATH; output made with TypeScript 5.9.3
node scripts/build-jsx.mjs --check

# 2. After changing a page's <script>, <style>, style="" attributes or stylesheets:
node scripts/csp.mjs
node scripts/csp.mjs --check
```

- Put page code in a `.js` file, never in an inline `<script>` or an `onclick=`; `csp.mjs` refuses
  inline handlers and `javascript:` URLs.
- A new third-party script needs a pinned URL and an `integrity` hash; `csp.mjs` then allows that
  exact URL. A new endpoint that page code fetches goes in `EXTRA_CONNECT` in `csp.mjs`.
- A `<meta>` policy cannot set `frame-ancestors` or reporting, and GitHub Pages sets no headers.
